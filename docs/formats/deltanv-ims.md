# DeltaNV, IMSToggle и WOTA (обновление конфигурации по воздуху)

Всё проверено на 11.00.17.00 HK; инструменты `tools/deltanv.py`, `work/deltanv_rf.py`, `work/volte_tab.py`.
Статусы: «измерено» — видно в данных/коде, «оценка» — вывод.

## 1. DeltaNV — дельта-правки NV поверх nvitem

### 1.1 Раздел DeltaNV (`*_deltanv.bin`, «BML delta NV Partition»)

Формат (little-endian, **без выравнивания**, `tools/deltanv.py`):

```
секция:  char name[20], u16 version, u32 size        (size = вся секция с заголовком)
элемент: u16 nv_id, u16 offset, u16 len, data[len]   → nv[nv_id][offset:offset+len] = data
         до nv_id == 0xffff или конца секции
```

- Раздел грузится в RAM `0x80988800` (макс 128 КБ), код `nv_hwversion_adpter.c` (KERNEL).
- Секции `hw_verNN`: `NN` — ревизия платы, читается со strap-GPIO (`0x80a2e55e`). Применяет
  `NV_Force_Change` (`0x80a30ca2`), если версия секции > версии, сохранённой в NV `0x16` байт `0x128`.
- **В 3210 обе секции пусты** (`hw_ver00` v0 и `hw_ver02` v1, размер 28, 0 элементов), а `NV_Force_Change`
  (путь `hw_ver`) не вызывается — эта часть механизма мёртвая.
- **Но сам раздел используется**: он — *первый источник* операторских профилей VoLTE.
  `[DELTA NV]: Merge SIM/PLMN delta nv` (`0x80e7760c` / `0x80e776e6`) делает так:
  1. применяет профиль по умолчанию (MCC/MNC `0xffff`) из блоба в ядре («modem bin», `0x80a30c80`);
  2. ищет профиль SIM-карты в **разделе DeltaNV** («delta nv bin», RAM `0x80988800`, `0x80a30c5e`);
  3. если не нашёл — берёт его из блоба в ядре.
  Поиск (`0x80e77462`) требует, чтобы раздел начинался с секции `DeltaNvIndex`. В стоке там `hw_ver00`
  → «No index found» → всегда срабатывает ядро. Раздел **не подписан**, и WOTA пишет в него файл `ims`
  (см. §3) — так HMD обновляет VoLTE-профили без новой прошивки. Значит, свой `DeltaNvIndex` + секции
  в этом разделе перекроют встроенные профили без правки кода (**оценка: не проверено на железе**).

### 1.2 Встроенный в ядро операторский блоб (файл `+0xaf7968` = адрес `0x814fd768`, 0x19000 байт)

Подписан вместе с ядром (внутри DHTB KERNEL_IMG), код `nvm_delta_nv.c`. Это **не отдельный раздел**:
WOTA его не меняет, но перекрывает — кладёт новый индекс в раздел DeltaNV (§1.1). В других сборках блоб лежит
по другому адресу (10.00: `0x814fd680`, 14.03: `0x81485bf0`, 15.00: `0x814878e0`); `tools/deltanv.py` ищет его
по сигнатуре. В 15.00 профилей уже 691 секция / 668 записей индекса.

- `DeltaNvIndex` — **651 запись** `{u16 mnc (bit15 = 3-значный), u16 mcc, u32 -1, u32 off_S, u32 off_P}`:
  по MCC/MNC вставленной SIM выбирается пара секций оператора (`0x80e77462`).
- **662 секции = 331 пара** `<CC>_<Operator>_P` / `_S`:
  - `_P` правит NV **2162** (IMS SIP/transport) — 681 правка;
  - `_S` правит NV **2160** (IMS service/media) — 2439 правок.
- Секции `hw_rfNNN` (hw_rf000/743/744/747) — дельта калибровок RF по id чипа, правит NV **1300**
  (у hw_rf743 — 15 правок); применяет `NV_Force_Change_Ex` (`0x80a30e86`), версия в NV `0x16` байт `0x129`.
- Россия (MCC 250): **7 операторов** — МТС (01), МегаФон (02), Yota (11), Tele2 (20), Летай (27),
  СБТелеком/СберМобайл (50), Билайн (99).

Итого блоб — это таблица подстройки IMS/VoLTE-параметров под оператора (и RF-калибровки под чип),
применяемая при загрузке в память; в файле `nvitem.bin` её нет.

## 2. IMSToggle — включение VoLTE по оператору

- Раздел `ims_toggle.bin` (**256 байт**): в стоке **пустой** (`0xFF`). Формат: заголовок `0xFACE` +
  записи по 16 байт (по `work/volte_tab.py`, «fallback when IMS TOGGLE partition has no 0xFACE header»).
- Раздел пуст → работает **встроенная таблица USER `0x8865eb50`** (**527 операторов**, 559 строк цикла):
  запись 16 байт `{u16 mcc, u16 mnc, байты-флаги}`. Читает `MMIPHONE_SetVolteConfigInfo` (`0x8836667a`),
  строка называет поля: `volte_icon_style`, `is_volte_icon_on`, `is_volte_set_display_on`, `is_volte_default_on`.
- **РФ (MCC 250): МТС/МегаФон/Tele2/Билайн имеют `is_volte_default_on = 0`** → VoLTE по умолчанию выключен
  (измерено по таблице). Всего в базе 404 оператора с `default_on = 1`.

## 3. WOTA (SWOTA HMD) — обновление по воздуху

Код в USER (`mmiwota_download.c`, `mmiwota_update.c`). Сервер: **`https://swota.hmdglobal.com/FOTA/SWOTAData`**
(строка в `MMIWOTA_SendPacFotaRequest`, `0x88512ff0`).

Два режима:
1. **PAC FOTA** — обновление прошивки файлом `.pac` (с SD-карты или по воздуху): `IsPacFileValidate`
   (проверка crc16/версии/продукта), `MMIWOTA_StartPacFota`.
2. **APN/IMS OTA** — конфигурационные данные (`MMIWOTA_StartApnOta`). Качает **4 файла** и пишет их
   в разделы флеша через `MMIWOTA_SaveBinToSect` (BSD-запись, `mmiwota_update.c`). По строкам
   `MMIWOTA_StartDownLoad` (`0x889b74b2`):

   | Флаг | Файл | Целевой раздел (BSD) | Функция |
   |---|---|---|---|
   | `--apn` | apn | `BML APN Partition` (`apn.bin`) | `0x889d5e2a` |
   | `--cnv` | config nv | `BML CONFIG NV Partition` (в `.pac` такого раздела нет) | `0x889d5ea8` |
   | `--ims` | ims | **`BML delta NV Partition`** (`*_deltanv.bin`) | `0x889d5f26` |
   | `--tog` | ckd | `BML IMS TOGGEL Partition` (`ims_toggle.bin`) | `0x889d5fa0` |

   Имена разделов и файлов — прямо из строк функций.

**Вывод:** APN / CONFIG NV / DeltaNV / IMSToggle — **отдельные разделы вне подписи**, и HMD может
перезаписать их по воздуху.

## 4. Что это значит для проекта

1. **Операторская дельта VoLTE (331 профиль) — в подписанном ядре**, сам блоб не редактируем, но его можно
   **перекрыть разделом DeltaNV** (§1.1) — тем же путём, каким это делает WOTA.
2. **APN / config-NV / IMS / ims-toggle — вне подписи, но их может перезаписать WOTA.** Значит, правки
   этих разделов не навсегда: телефон может откатить их по воздуху при следующем чеке SWOTA.
3. **IMSToggle раздел пуст → работает встроенная таблица USER (подписанная).** Но судя по логике
   «fallback», записанный собственный `ims_toggle` (256 байт, заголовок `0xFACE`) перекроет встроенную
   таблицу — это путь менять VoLTE-по-умолчанию без правки кода. **Не проверено на железе** — оценка.
4. **Раздел DeltaNV** — путь `hw_ver` мёртвый, но раздел как источник профилей VoLTE живой (§1.1).

Инструменты: `python3 -I tools/deltanv.py <deltanv.bin | EXEC_KERNEL_IMAGE.bin> [mcc]`,
`work/.venv/bin/python work/volte_tab.py`.
