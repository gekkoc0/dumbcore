# Раздел APN (`apn.bin`, «BML APN Partition»)

База настроек мобильного интернета, MMS, IMS (VoLTE) и XCAP для операторов всего мира: телефон
при старте выбирает из неё записи под MCC/MNC вставленной SIM-карты. Разобран по 11.00 HK и проверен на всех 8 сборках:
каждая разбирается до последнего байта, записи идут встык.

Код (USER, `mmiconn_manager_wintab.c`):
- `LoadNetworkAccountInfoFromOtaSection` 0x88a1c9e2 — читает раздел;
- `ParseNetworkAccountInfo` 0x88a1c63a — разбирает записи и оставляет только записи с MCC/MNC текущей SIM-карты;
- 0x88a1d16e — переносит запись в настройку соединения (имена полей видны в отладочном дампе 0x882fb714).

Раздел не подписан (нет заголовка DHTB), как и NV с ресурсами.

## Заголовок

| Смещение | Что |
|---|---|
| 0x00 | `char[16]`, 16 символов `0` (версия базы?) |
| 0x10 | `u32` размер = размер файла − 0x14 |
| 0x14 | `OTAC`, `u16` версия = 2, `u16 count` (4279 в 11.00) |
| 0x1C | `u32 offset[count]` — от начала `OTAC` |

## Запись

| +  | Тип | Поле | Значения |
|---|---|---|---|
| 0x00 | u16 | ip_type | 0 IPv4, 1 IPv6, 2 IPv4v6 |
| 0x02 | u16 | uiorder | порядок в списке; 5 почти у всех |
| 0x04 | u16 | mcc | 250 = Россия |
| 0x06 | u16 | mnc | |
| 0x08 | u16 | port | порт прокси, 0 — без прокси |
| 0x0A | u8 | access_type | 1 (0 только в пустой последней записи) |
| 0x0B | u8 | is_customed_detail | флаг «запись кастомизирована» (в настройке поле +0x133; имя из дампа `FUN_882fb714`); 1 у 210 записей (Vodafone GR, IMS/HOS ряда операторов) | измерено: имя поля в коде |
| 0x0C | u8 | auth_type | 0 нет, 1 PAP, 2 CHAP, 3 PAP или CHAP |
| 0x0D | u8 | account_type | 0 интернет, 1 MMS, 5 IMS (VoLTE), 8 XCAP/Ut («hos»), 9 SOS (экстренные), 6 — редкий (11 шт., visible=0, имена «IA»/«Internet Access»/«webphone»; «IA = Internet Access» — оценка) |
| 0x0E | u8 | mvno_type | как сверять `mvno_value`: 0 нет, 1 SPN (имя оператора), 2 GID, 3 PNN, 4 префикс IMSI, 5 диапазон IMSI |
| 0x0F | u8 | visible | 0 — скрыта в списке (например, IMS) |
| 0x10 | u8 | domestic_roaming? | похоже на «разрешён национальный роуминг»: 1 только у 84 записей виртуальных операторов (iliad, Kena, PosteMobile, CoopVoce…) | **оценка**: в настройку соединения байт не переносится (0x88a1d16e); `MMICONNECTION_IsSupportDomesticRoaming` (`FUN_88a1b27a`) читает не его, а NV 674 |
| 0x11 | u8 | roaming_ip_type | те же коды, что ip_type; почти всегда совпадает с ним |
| 0x12 | 9 строк | | `{u16 len, data[len]}` |

Строки по порядку (в скобках — сколько символов оставляет прошивка): имя в UTF-16LE (28), прокси (80), DNS1 (15),
DNS2 (15, в настройку не переносится), логин (30), пароль (30), APN (30), домашняя страница / MMSC (40), `mvno_value` (40).
В `data` лежит строка, после неё хотя бы один нулевой символ, и нулями добито так, чтобы всё поле `2 + len` было кратно 4.
