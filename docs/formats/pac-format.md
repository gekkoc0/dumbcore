# Контейнер прошивки `.pac` (BP_R1.0.0)

Стандартный контейнер Spreadtrum/Unisoc, который читают ResearchDownload / UpgradeDownload и `spd_dump`.
Разобран полностью: **все 8 прошивок собираются инструментом заново байт в байт**, обе контрольные суммы сходятся.
Числа little-endian, строки UTF-16LE.

## Заголовок `PAC_HEADER` (0x84c байт)

| Смещение | Что |
|---|---|
| 0x000 | версия формата, 24 символа: `BP_R1.0.0` |
| 0x030 | u32 размер всего `.pac` |
| 0x034 | продукт, 256 символов: `UMS9117` |
| 0x234 | имя прошивки, 256 символов: `MOCOR_MOCOR_20A_MP_W22.04.6_P5` |
| 0x434 | u32 число файлов (28 или 29) |
| 0x438 | u32 смещение таблицы файлов = 0x84c |
| 0x43c… | режим, тип флеша (1 = NAND), стратегия NAND, флаг бэкапа NV, тип страницы, псевдоним продукта (100 символов), флаги OMA DM / preload, резерв |
| 0x844 | u32 сигнатура `0xFFFAFFFA` |
| 0x848 | u16 **CRC1** = CRC-16/ARC (полином 0xA001 отражённый, начальное 0) байтов `[0, 0x848)` |
| 0x84a | u16 **CRC2** = CRC-16/ARC байтов `[0x84c, конец)` — всё, кроме заголовка |

## Таблица файлов `FILE_T` (по 0xa14 байт)

| Смещение | Что |
|---|---|
| 0x000 | u32 размер записи = 0xa14 |
| 0x004 | ID раздела (256 символов): `FDL`, `NV`, `BOOT0`, `UserImg`, `MMIRes`, `APN`… |
| 0x204 | имя файла (256 символов) |
| 0x404 | версия (256 символов) |
| 0x604 | u32 размер файла (0 — служебная запись без данных: стирание, OmaDM и т. п.) |
| 0x608, 0x60c | флаги (из XML: Flag, CheckFlag) |
| 0x610 | u32 смещение данных в `.pac` (0, если данных нет) |
| 0x614… | флаг «можно пропустить», число адресов, адреса раздела (`0x90000004` для MMIRes…), резерв |

Данные файлов идут сразу за таблицей, в её порядке, без выравнивания. Конец последнего файла = конец `.pac` = поле
размера. Отдельных контрольных сумм у файлов в контейнере нет.

## Сборка (`tools/pacwrite.py`)

```bash
python3 -I tools/pacwrite.py <исходный.pac> <новый.pac> MMIRes=<новый mmi_res.bin>
python3 -I tools/pacwrite.py <любой.pac> --verify
```

Инструмент меняет данные указанных разделов, пересчитывает размеры, смещения, общий размер и обе CRC.
Перед сохранением он сверяет разметку и содержимое всех разделов с ожидаемыми данными. Готовый файл
заменяет предыдущий результат после завершения записи. Команда `--verify` проверяет сигнатуру и размер
контейнера, обе CRC, границы таблицы и пересечения разделов. При ошибке команда завершается с ненулевым кодом.

Подписанные образы (`FDL`, `FDL2`, `BOOT0`, `BOOT1`, `KernelImg`, `UserImg`) заменять **отказывается**: их проверяет
Secure Boot (docs/internals/secureboot.md). Ресурсы, NV, APN, DeltaNV и IMSToggle не подписаны.

## Проба

`work/mod_test/demo_11.00_HK.pac` — официальная 11.00 HK, в которой заменён только MMIRes: зелёная иконка калькулятора,
пункт «Сообщения» в русском меню переименован в «СМС», часы на рабочем столе — оранжевые (`COLOR_RES_IDLE_TIME`).
Распаковка проверена: изменился один раздел, внутри лежит ровно наш файл, все остальные разделы совпадают побайтно.
MMIRes на 8 байт больше заводского (старая строка «Сообщения» нужна в других местах, новая добавилась).

## Автоматические проверки

`python3 -I tools/test_pacwrite.py` прогоняет `dumbcore pac` и `pacwrite.py --verify` на искусственном контейнере.
Тесты покрывают побайтовую пересборку, изменение размера ресурсов, отказы при недопустимой замене, повреждение CRC
и ошибки разметки при корректных CRC. Для запуска достаточно Python 3.

## Что не проверено и о чём помнить

- **Ни один собранный `.pac` не прошивался.** Прежде чем шить: бэкап своей 16.00 (docs/links.md).
- Ёмкость раздела MMIRes на флеше неизвестна. Размеры в таблицах для бэкапа на форуме — это размеры файлов конкретной
  прошивки, а не разделов. Пока безопаснее держать новый ресурсный файл не больше заводского (PT Sans добавляет ~72 КБ;
  в RU-сборках, судя по модам, нет китайских шрифтов на 12 МБ, место там, скорее всего, есть — проверим по бэкапу).
- Демо собрано на официальной 11.00 HK. Для своего телефона правки надо делать поверх **своей** прошивки
  (16.00 RU из бэкапа) — смешивать разделы разных версий нельзя (форум: размеры блоков у регионов разные).
- При прошивке ResearchDownload позволяет снять галочки со всех разделов, кроме нужного; для правки интерфейса нужен
  только MMIRes (и FDL для загрузки). Порядок действий распишем отдельно, когда дойдём до прошивки.
