# DumbCore

Открытый набор инструментов и знаний для разбора и правки прошивки кнопочного **Nokia 3210 4G (2024)**,
TA-1618 (Unisoc UMS9117 / Mocor RTOS / S30+). Инструменты рассчитаны на macOS и Linux, нужен Python 3.

> ✅ **Проверено на Nokia 3210 4G TA-1618 с ПО 16.00.17.00 и macOS.** Команда `dump full` сохранила 25 файлов,
> а `verify` на свежем бэкапе прошла 8 из 8 проверок. В отдельном опыте новая иконка была записана по USB,
> прочитана обратно байт в байт и появилась после загрузки телефона.
>
> ⚠️ Ещё не проверялось на телефоне: замена шрифта и звуков, правка заводского NV и главного меню, прошивка собранного `.pac`
> официальными программами. Делайте это только на свой риск и только имея свой бэкап.

## Что умеет

- **Бэкап телефона** по USB: чтение основных разделов и отдельные режимы для скрытых областей ([docs/backup.md](docs/backup.md)).
- **Проверка на оригинальность**: подписи кода, IMEI, (опционально) ключ в eFuse — без передачи данных куда-либо
  ([docs/verify.md](docs/verify.md)).
- **Запись на телефон** по USB — раздел ресурсов (проверено) или рабочий NV, с чтением назад и сравнением.
- **Ресурсы** (`mmi_res`, формат `sres0001`): картинки (ABMP/ABMR/sabm/SJPG/BMP), анимации (SMOV/VM, GIF), шрифты SPML,
  тексты на всех языках, цвета, звуки — читать, выгружать и **заменять**; энкодеры повторяют стоковые байт в байт.
- **Шрифты**: заменить заводские латиницу и кириллицу на свой TrueType.
- **NV**: карта записей, главное меню (порядок и состав пунктов — одна запись NV 680).
- **APN, DeltaNV, IMSToggle**: разбор форматов, выгрузка APN в CSV.
- **`.pac`**: распаковка и пересборка с заменёнными разделами (контрольные суммы пересчитываются, подписанные
  образы не трогаются).
- **Макет телефона в браузере**: рабочий стол, главное меню, списки и простые приложения на настоящих ресурсах
  прошивки — видно свои правки до записи на телефон.

## Установка

```sh
python3 -m pip install -r requirements.txt      # Pillow; capstone — только для инструментов дизассемблера
```

Для бэкапа дополнительно нужен `spd_dump` — см. [docs/backup.md](docs/backup.md).

## Команды

Единая точка входа — `tools/dumbcore.py` (`python3 -I tools/dumbcore.py help`):

| Команда | Что делает |
|---|---|
| `dump test\|full\|extra\|scan\|hidden\|nvrun` | бэкап телефона, только чтение |
| `verify <папка полного бэкапа> [--efuse файл]` | проверить подписи прошивки и заводские данные |
| `trim <mmi_res из бэкапа> <файл>` | обрезать ресурсы до реальных данных перед правкой |
| `write 0x90000004 <mmi_res>` | **записать** ресурсы в телефон (подтверждение словом `WRITE`) |
| `inspect <файл>` | разобрать файл: ресурсы, `.pac`, образ кода, APN, диск FAT, NV |
| `images <mmi_res> <папка>` | выгрузить все картинки и анимации |
| `edit <src> <dst> <правки…>` | заменить картинки, тексты, цвета, звуки, анимации |
| `font <src> <dst> <шрифт.ttf>` | поставить свой шрифт |
| `menu <nvitem>` | показать главное меню из NV |
| `apn <apn.bin> [--csv файл]` | база APN |
| `mockup <mmi_res> <nvitem> <user.bin> [папка]` | макет телефона в браузере |
| `pac <исходный.pac> <новый.pac> Раздел=файл…` | собрать `.pac` |

Первый опыт на 16.00 — [изменить цвет «Контактов» и сравнить два макета](docs/guide.md#3-поменять).

Пошаговый рецепт «бэкап → правка → проверка в макете → запись» — **[docs/guide.md](docs/guide.md)**.
